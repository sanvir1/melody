🎶 Музыкальный проигрыватель

Как пользоваться:

  1. Выберите файл мелодии из списка слева.
  2. Введите мелодию в поле ниже или загрузите текстовый файл.
  3. Используйте цифры для нот: 1 = C4, 2 = D4, 3 = E4, ....
  4. Разделяйте ноты без пробелов (например, 53353354321).
  5. Используйте пробел как паузу (например, 53 35 33 54321).
  6. Используйте ползунок для изменения длительности нот (от 0.1 до 2 секунд).
  7. Загрузите файл настроек частот для нот (JSON-формат).
  8. Нажмите кнопку "Проиграть мелодию".

Пример: 53 35 33 54321

Примечание: Длительность нот и пауз можно изменить с помощью ползунка. Настройки частот можно загрузить через JSON-файл.
